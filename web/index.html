Classes de rima disponíveis

Clique numa classe para copiar a chave para o campo Rima A, B ou C. A chave é a terminação ortográfica que define a classe.

Modelo treinado em obras de Camões. A contagem de sílabas usa a tabela pré-calculada do vocabulário; para palavras fora do vocabulário recorre a uma heurística de núcleos vocálicos.
